# KhojIQ

**Sell by vibe. Not by filters.**

KhojIQ is a vision-based product search platform for boutiques. This repository contains the landing page website hosted at [khojiq.github.io](https://khojiq.github.io).

## Features

- Vision-based search for clothing, shoes, and bags
- AI-powered auto-descriptions from product photos
- Natural language search (e.g., "A dress for a winter wedding—elegant, not too formal")
- Visual similarity search
- Built-in styling assistance

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 3.4
- shadcn/ui components

## Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

## Deployment

The site is automatically deployed to GitHub Pages when changes are pushed to the main branch.
